## Project Context

**Goal**: Build `AssetManager.py` - a Python UI tool for managing AI prompt ingredients and building `.agent/` folders.

**Current State**: Greenfield development
- Clean slate Python application
- Architecture informed by PLAN-AiPrompts-AssetManager-v1.md
- Desktop-first (Windows), cross-platform aspirational

**Key Responsibilities**:
1. **Registry Management**: CRUD operations on `registry.json` (ingredient catalog)
2. **Version Management**: Create new versions (`{topic}-{major}-{minor}.md`) and update registry pointers
3. **Agent Builder**: Copy ingredients from registry → `.agent/` folders based on `agent.config.json`
4. **UI**: Modern, intuitive customtkinter interface

**Design Principles**:
- SOLID architecture (separate concerns: UI, business logic, file I/O)
- Repository pattern for JSON operations
- Service layer for complex workflows
- Fail-fast with clear error messages

### 2. File I/O Conventions

**Always use Path objects:**
```python
from pathlib import Path

# ✅ GOOD
def copy_ingredient(src: Path, dest: Path) -> None:
    dest.parent.mkdir(parents=True, exist_ok=True)
    dest.write_text(src.read_text(encoding="utf-8"))

# ❌ BAD
def copy_ingredient(src: str, dest: str) -> None:
    ...
```

**Error Handling:**
```python
try:
    content = ingredient_path.read_text(encoding="utf-8")
except FileNotFoundError:
    logger.error("ingredient_not_found", path=str(ingredient_path))
    raise
except PermissionError:
    logger.error("permission_denied", path=str(ingredient_path))
    raise
```

class RegistryPanel(ctk.CTkFrame):

    try:
        self._service.add_ingredient(name, path)

        from tkinter import messagebox
